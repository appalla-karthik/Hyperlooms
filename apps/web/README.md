# HYPER_LOOMS Web

The Next.js dashboard is the browser surface for consumers, providers, and future administrators. Phase 0 displays an honest foundation status page and establishes strict TypeScript, lint, format, test, and production-build checks.

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm build
```

Authoritative scheduling, trust, and accounting rules belong to the Spring Boot control plane, not this application.

Build the production container from the repository root so the workspace lockfile is available:

```powershell
docker build -f apps/web/Dockerfile -t hyperlooms-web:foundation .
```
